# Hinter dem Horizont

Eine begehbare 3D-Welt mit glaubwürdigen Orten. Die Reise beginnt an der Felsenburg.

Oberstes Gebot: Real Life. Architektur, Maßstab, Licht und Bewegung orientieren sich an der Wirklichkeit.

Die aktuelle Vorschau zeigt das Außenmodell. Auf einer Webadresse lässt es sich in 3D drehen und zoomen.
